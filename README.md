## 🌟 核心特色

### 1. 以廣達為核心樞紐的「上下游直觀流程大圖」
- **廣達的上游（Upstream）**：
  - 運算核心：輝達 (NVIDIA)、超微 (AMD)、台積電 (2330 先進製程與 CoWoS 封裝)
  - 散熱水冷：奇鋐 (3017)、雙鴻 (3324)、建準 (2421)、健策 (3653)
  - 重型滑軌：川湖 (2059，手握 3,000 項專利壁壘，市占逾 60%)
  - 機殼機構：勤誠 (8210)、晟銘電 (3013)
  - 高瓦數電源：光寶科 (2301)、台達電 (2308)
  - 高階材料與線材：台光電 (2383)、金像電 (2368)、貿聯-KY (3665)
  - 記憶體：SK海力士、美光 (HBM3e / DDR5)
- **廣達的中游（Midstream Hub）**：
  - 廣達 (2382) ＋ 旗下雲端白牌子公司 **雲達科技 (QCT)**
  - 完整 L6 (主機板貼裝) ➔ L10 (次系統節點) ➔ L11 (整機機櫃系統整合) ➔ L12 (資料中心現場部署) 一條龍製程。
- **廣達的下游（Downstream）**：
  - 北美四大 CSP 超大規模雲端巨擘：微軟 (Azure)、Google (GCP)、亞馬遜 (AWS)、Meta (Facebook)
  - 終端品牌與車用電子：蘋果 (MacBook 筆電主力代工)、特斯拉 (Tesla 車載電腦與自駕 ECU)

### 2. 一億元 AI 伺服器機櫃（GB200 NVL72）BOM 表成本結構拆解

- 導軌與機殼：佔比 ~3%
- 集中式電源機箱：佔比 ~3%

### 4. 新聞與市場情報中心（news.html）
- 獨立頁面，由六頁共用的頁首切換列進入（類股中樞／投資策略與訊號／投資方案規劃／龍頭個股專頁／新聞情報／廣達專頁）。
- **盤面速覽**：16 檔依最新交易日漲跌幅排序的收盤報價卡。
- **三大法人買賣超**：可切換當日／近 5 日／近 20 日，表頭可排序。
  三大法人數據由證交所收盤後公布，頁面明確標示而非宣稱即時。
- **類股新聞牆**：彙整 16 檔相關新聞，可依個股篩選。
  同一則報導若同時提及多檔會合併；被多家媒體轉載者亦合併並標示「等 N 家」。
- 資料更新：`python scripts/build_news.py`（滾動保留最近 10 天）

### 5. 投資策略與訊號中心（strategy.html）
- 獨立頁面，由四頁共用的頁首切換列進入。把既有的日線、籌碼、指數與新聞資料
  換算成**規則透明**的技術面＋籌碼面訊號。
- **類股階段研判**：以類股指數均線位置、對大盤的相對強度與市場廣度
  （16 檔中有幾檔站上 MA20），判定目前是擴張／整理／收縮期。
- **規則式評分**：總分 = 趨勢面 35% + 動能面 25% + 籌碼面 25% + 相對強度 15%，
  每一條加分規則與配分都攤開顯示，不是黑箱分數。
- **參考進出場價位**：進場給區間不給單一價位；停損為進場區下緣減 N 倍 ATR（上限 -12%）；
  第一目標認 60 日高點或季線等真實壓力區；另附風險報酬比與預估持有天數。
  跌破月線的個股一律標示「需先站回月線」而非直接給買點。
- **當日事件警示**：大漲大跌、爆量、創 60 日新高低、均線突破跌破、MACD 翻多翻空、
  法人異常買賣超、關鍵字命中的新聞，依嚴重度與多空方向分級。
- **問答機器人**：本地規則引擎，讀同一份 `signals.json` 回答，
  **零金鑰、零後端、斷網可用**，回答必定與頁面數字一致。
  可問選股、進出場、籌碼、技術指標、名詞解釋與個股比較。
- **歷史回測**：以 2023 年起約 4 年、16 檔的資料回放同一套規則（`scripts/backtest_signals.py`），
  統計勝率、獲利因子、超額報酬與投組最大回撤，並對照同期買進持有。
  回測與線上訊號共用 `scripts/signal_rules.py`，確保驗證的就是線上那一套規則。
- 內容為規則運算結果，**不構成投資建議**，頁面置頂有不可折疊的免責聲明。
- 資料更新：`python scripts/build_signals.py`（不連網，須排在其他腳本之後）

### 6. 投資方案規劃器（plan.html）
- 互動式工具：輸入打算投入的金額、投資型態、單筆可承受虧損與持有檔數，
  算出一份具體到張數的資金配置方案。**全部在瀏覽器端運算，不上傳任何輸入。**
- **教學為主**：頁面前半段先教三件事 —— 選股在看什麼、
  **風險預算法**（先決定能賠多少再反推買多少）、以及分散與環境的意義。
- **每個數字都附算式**：每檔部位下方會攤開
  「單筆風險金額 → 停損距離 → 風險反推部位 → 集中度上限 → 實際股數」整串推導。
- **依類股階段自動調整曝險上限**（擴張 100%／整理 60%／收縮 30%），
  比例取自回測各階段的實際期望值。
- **情境試算**：全部停損 / 一半停損一半達標 / 全部達標，各會賺賠多少（已扣交易成本）。
- **台股真實限制**：一張 1000 股、零股拆分、手續費最低 20 元、證交稅 0.3%。
  這個類股高價股多（緯穎一張逾 167 萬），買不起的個股會明確標示而非略過。
- **三道硬性閘門**：非閒置資金、借貸／融資資金、金額過小，前兩者直接拒絕產生方案。
- 這是一台計算機，**不是投資顧問**，也不會替使用者決定該投入多少錢。

### 7. 龍頭個股專頁（stock.html）
- 五大子族群的領軍龍頭（華碩 2357、川湖 2059、奇鋐 3017、研華 2395、致伸 4915）
  各有專屬網址 `stock.html?id=股號`，比照廣達旗艦專頁的七章節配置：
  公司簡介與產品 → 300 日量價走勢（收盤線⇄K 線、5 種期間、MA20/MA60）→ 財報獲利三率
  → 專屬樹狀產業鏈拓撲（點擊高亮關聯）→ 上下游供應鏈明細 → 籌碼面 → 規則訊號定位。
- 以**單一樣板 + 資料驅動**實作，而非複製 5 份 HTML，避免版面與邏輯日後漂移。
- 長期日線由 `scripts/build_leader_history.py` 增量累積（不連網），
  產出 `data/leaders_history.json`。
- 廣達 2382 維持內容更深的 `quanta.html`，頁內切換器會標示為「旗艦專頁」。

### 8. 類股指數 vs 大盤強弱對照（資金輪動）
- 資料來自證交所 MI_INDEX，單次請求同時取得「電腦及週邊設備類指數」與「發行量加權股價指數」。
- 兩者點數尺度相差百倍（約 345 vs 38,000），**一律指數化到區間起點 = 100 後同軸比較**，
  不使用雙軸（雙軸的對齊位置是任意的，會製造出資料中不存在的相關性）。
- 另附相對強度 RS 圖（類股 ÷ 大盤），100 以上代表強於大盤。
- 含 4 張摘要卡、依實際數據自動生成的輪動解讀、數據表格，支援近 1／3／6 個月與全區間切換。
- 平日收盤後由 GitHub Actions 自動補當日資料；手動更新：`python scripts/build_index_compare.py`

### 9. 每日收盤報價（證交所 MIS）
- 收盤後由排程抓取證交所 MIS 的 13:30 收盤快照，寫成 `data/realtime.json` 提交回 `main`；
  網頁讀同源靜態檔，**零後端、不需要 CORS 繞道**。
- 全站所有資料（報價、法人、指數、新聞）一律每日更新一次，頻率一致。
- 畫面標示為「收盤價 YYYY-MM-DD 13:30:00（證交所 MIS）」，**不宣稱即時**。
- 手動更新：`python scripts/fetch_realtime_quotes.py`

### 10. 還原股價（除權息 + 股票分割回溯調整）
- FinMind 與 TWSE 原始資料皆為 **未還原** 股價，除權息或分割後 K 線會出現假斷崖。
- `scripts/adjust_prices.py` 採兩層機制：
  1. **除權息還原（精確）**：取 FinMind `TaiwanStockDividend` 的實際配息配股金額，
     以 `(前收盤 − 現金股利) / (1 + 股票股利/10)` 算出因子。
  2. **分割偵測（後備）**：只在除權息還原後仍有 ±25% 以上跳空時才啟動。
- 已還原的事件：廣達 3 筆現金股利、緯穎 1 筆大額股票股利（配股率 1.98279）、
  神達 1 筆現金+股票混合配發等，共 8 筆。
- 川湖 (2059) 的真實連續下跌不會被誤判調整。
- 先 dry-run：`python scripts/adjust_prices.py`，確認後再加 `--apply`。

### 11. 量價圖支援「收盤線圖 ⇄ K 線圖」切換
- 以 Chart.js 原生浮動長條繪製蠟燭 K 棒（影線為當日最高／最低，實體為開盤↔收盤），**未引入任何額外圖表函式庫**。
- 台股慣例配色：紅 K = 收盤 ≥ 開盤、綠 K = 收盤 < 開盤；成交量柱色與 K 棒同步。
- 價格面板與成交量面板上下分離、Y 軸等寬對齊日期軸（不使用雙軸，避免製造假相關）。
- 廣達專頁疊加 MA20／MA60 並支援 1 個月～全週期過濾；首頁個股彈窗疊加 MA20。

### 12. 籌碼面：三大法人動向與外資持股結構
- 串接 FinMind 開放資料，涵蓋 16 檔個股近 80 個交易日的 **外資／投信／自營商每日買賣超**（單位：張）與 **外資持股比例**。
- 首頁每檔個股彈窗、廣達旗艦專頁章節 6 均提供：摘要數字卡、每日買賣超堆疊柱狀圖、外資持股比例走勢圖與數據表格。
- 支援近 20／40／60 日（廣達專頁另有全區間）切換，並依實際數據自動生成籌碼結構解讀。
- 資料更新指令：`python scripts/build_institutional_data.py`
