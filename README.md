# 廣達 (2382) 與 AI 伺服器產業鏈全景地圖 · Quanta Supply Chain Atlas

本專案為專門針對台灣科技硬體龍頭 **「廣達電腦 (2382)」及其所處的 AI 伺服器與雲端資料中心產業** 設計之全圖解產業鏈地圖獨立網站。

🔗 **線上展示網址**：[https://itachi923.github.io/quanta-ai-supply-chain/](https://itachi923.github.io/quanta-ai-supply-chain/)

## 🌟 核心特色

### 1. 以廣達為核心樞紐的「上下游直觀流程大圖」
- **廣達的上游（Upstream）**：
  - 運算核心：輝達 (NVIDIA)、超微 (AMD)、台積電 (2330 先進製程與 CoWoS 封裝)
  - 散熱水冷：奇鋐 (3017)、雙鴻 (3324)、建準 (2421)、健策 (3653)
  - 重型滑軌：川湖 (2059，手握 3,000 項專利壁壘，市占逾 60%)
  - 機殼機構：勤誠 (8210)、晟銘電 (3013)
  - 高瓦數電源：光寶科 (2301)、台達電 (2308)
  - 高階材料與線材：台光電 (2383)、金像電 (2368)、貿聯-KY (3665)
  - 記憶體：SK海力士、美光 (HBM3e / DDR5)
- **廣達的中游（Midstream Hub）**：
  - 廣達 (2382) ＋ 旗下雲端白牌子公司 **雲達科技 (QCT)**
  - 完整 L6 (主機板貼裝) ➔ L10 (次系統節點) ➔ L11 (整機機櫃系統整合) ➔ L12 (資料中心現場部署) 一條龍製程。
- **廣達的下游（Downstream）**：
  - 北美四大 CSP 超大規模雲端巨擘：微軟 (Azure)、Google (GCP)、亞馬遜 (AWS)、Meta (Facebook)
  - 終端品牌與車用電子：蘋果 (MacBook 筆電主力代工)、特斯拉 (Tesla 車載電腦與自駕 ECU)

### 2. 一億元 AI 伺服器機櫃（GB200 NVL72）BOM 表成本結構拆解
- 晶片端（GPU/CPU）：佔比 ~68%
- 記憶體（HBM3e）：佔比 ~11%
- 廣達系統組裝代工與服務毛利：佔比 ~6%（單櫃毛利達 500~600 萬元）
- 液冷水冷系統：佔比 ~5%
- PCB 與高速線材：佔比 ~4%
- 導軌與機殼：佔比 ~3%
- 集中式電源機箱：佔比 ~3%

### 3. 擴張至整個科技硬體產業鏈大圖
- 涵蓋階段一（半導體晶圓）、階段二（零組件）、階段三（系統組裝代工）、階段四（雲端與品牌終端）。

### 4. 盤中即時報價（證交所 MIS）
- 由 GitHub Actions 每 5 分鐘抓取證交所 MIS 盤中報價，推送至 `data-live` 分支；
  網頁經 `raw.githubusercontent.com` 讀取，**零後端、不需要 CORS 代理**。
- 廣達專頁頂部 Ticker 與首頁 16 檔卡片／比較矩陣皆顯示盤中價，並誠實標示實際報價時間。
- 三層後備：`data-live` 快照 → 專案內 `data/realtime.json` → FinMind 日線收盤。
- 手動更新：`python scripts/fetch_realtime_quotes.py`

### 5. 還原股價（股票分割回溯調整）
- FinMind 與 TWSE 原始資料皆為 **未還原** 股價，個股分割後 K 線會出現假斷崖。
- `scripts/adjust_splits.py` 偵測單日變動 > ±25%、價格比值接近常見分割倍數、
  且成交量同步放大的斷點，對該日之前的 OHLC 回溯調整。
- 已修正緯穎 (6669) 2026-09-02 的 1:3 分割；川湖 (2059) 的真實連續下跌不會被誤判。
- 先 dry-run：`python scripts/adjust_splits.py`，確認後再加 `--apply`。

### 6. 量價圖支援「收盤線圖 ⇄ K 線圖」切換
- 以 Chart.js 原生浮動長條繪製蠟燭 K 棒（影線為當日最高／最低，實體為開盤↔收盤），**未引入任何額外圖表函式庫**。
- 台股慣例配色：紅 K = 收盤 ≥ 開盤、綠 K = 收盤 < 開盤；成交量柱色與 K 棒同步。
- 價格面板與成交量面板上下分離、Y 軸等寬對齊日期軸（不使用雙軸，避免製造假相關）。
- 廣達專頁疊加 MA20／MA60 並支援 1 個月～全週期過濾；首頁個股彈窗疊加 MA20。

### 7. 籌碼面：三大法人動向與外資持股結構
- 串接 FinMind 開放資料，涵蓋 16 檔個股近 80 個交易日的 **外資／投信／自營商每日買賣超**（單位：張）與 **外資持股比例**。
- 首頁每檔個股彈窗、廣達旗艦專頁章節 6 均提供：摘要數字卡、每日買賣超堆疊柱狀圖、外資持股比例走勢圖與數據表格。
- 支援近 20／40／60 日（廣達專頁另有全區間）切換，並依實際數據自動生成籌碼結構解讀。
- 資料更新指令：`python scripts/build_institutional_data.py`

### 8. 產業鏈連鎖反應試算器
- 互動模擬北美 CSP 資本支出上修、晶片水冷化、GB200 放量出貨時，產業鏈各環節受惠順序。
